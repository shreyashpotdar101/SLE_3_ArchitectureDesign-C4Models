## 1. AI Assistance

ChatGPT was used to understand the C4 architecture model, organize the system architecture, and improve the clarity of the diagrams and documentation.

### Understanding the C4 Model

AI assistance was used to:
- Understand the four C4 architecture levels.
- Identify the purpose of Context, Container, Component, and Code diagrams.
- Connect the SLE-3 architecture with the previous SLE-2 BFS and DFS implementation.

### Level 1 – Context Diagram

ChatGPT assisted in identifying:
- User
- Graph Search System (BFS/DFS)
- Search Result / Path Output
- Input and output interactions

### Level 2 – Container Diagram

ChatGPT assisted in organizing the six main containers:
- Input Module
- Graph / Problem Representation
- Search Engine
- Visited / Memory
- Goal Test & Path Handling
- Output Module

### Level 3 – Component Diagram

ChatGPT assisted in identifying the internal components of the Search Engine:
- BFS / DFS Controller
- Frontier (Queue / Stack)
- Explored / Closed Set
- Goal Test
- Path Reconstructor

### Level 4 – Code Level Overview

ChatGPT assisted in connecting the architecture with the actual SLE-2 implementation:
- `bfs(graph, start, goal)`
- `dfs(graph, start, goal)`
- `graph`
- `visited`
- `path`
- `nodes_expanded`

### Documentation Support

ChatGPT also assisted in:
- Preparing short explanations for each diagram.
- Explaining architecture design decisions.
- Organizing the SLE-3 report.
- Preparing the README and AI Contribution Log.
